# Reflection: Daily Cloud Integration and Version Control in Modern Development

Cloud computing and version control systems have become foundational pillars of how we interact with technology, learn, and build software. Recognizing how these concepts manifest in our everyday routines bridges the gap between abstract academic theory and practical application.

### 1 & 2. Cloud Services I Use and Their Models
In my daily academic and personal life, I regularly rely on Google Drive, GitHub, and Canva. 
- **Google Drive (SaaS / Public Cloud):** Google Drive is delivered entirely through the web browser or mobile app, requiring no backend infrastructure management on my part, classifying it as **Software as a Service (SaaS)**. It operates on a **Public Cloud** deployment model because the underlying hardware and infrastructure are owned and managed by Google, serving millions of external users over the public internet.
- **GitHub (SaaS / Public Cloud):** As a version control hosting platform, GitHub provides a fully managed collaborative environment for developers, making it a **SaaS** solution. It is hosted on a **Public Cloud** infrastructure, allowing developers worldwide to store codebases, track issues, and collaborate openly or privately under standardized cloud protocols.
- **Canva (SaaS / Public Cloud):** Canva is a graphic design platform accessed entirely via the cloud without local software installations, fitting the **SaaS** model. It uses a **Public Cloud** deployment model because its rendering engines, templates, and asset libraries are hosted remotely and scaled dynamically for global users.

### 3. Git & GitHub for Cloud Projects
Version control is critical when working with cloud infrastructure because cloud environments are dynamic, collaborative, and prone to rapid iteration. Git and GitHub allow development teams to track incremental changes, maintain version histories, and roll back broken configurations safely. When managing cloud resources—such as Infrastructure as Code (IaC) scripts—GitHub provides a single source of truth, eliminating configuration drift and synchronization errors among distributed teams.
